# mathslug.github.io

Personal site for John Bentley. Static HTML, CSS, and JS. No frameworks.

## Structure

```
index.html          Main page
styles.css          Styles
images/             Project images and videos
favicon-*.png       Favicons
site.webmanifest    PWA manifest
```

## Deployment

Push to `main` and GitHub Pages will serve it at mathslug.github.io.
